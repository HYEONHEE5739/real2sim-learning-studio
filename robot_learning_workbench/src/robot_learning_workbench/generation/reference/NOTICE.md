# Isaac Lab Mimic calculation subset

Derived from installed Isaac Lab2.3.0 / Mimic1.0.15 and the pinned v8 portable reference. Copyright/SPDX and BSD/Apache licenses are preserved. UPSTREAM.json retains installed source identities. Pure function/class bodies are unchanged except import relocation and documented removal of execution/I/O entry points. No new generic framework, multi-arm/SkillGen support, IK solver or engine adapter is implemented. Workbench source_pool consumes official EpisodeData already provided by Native Dataset C; it does not define a storage format.
